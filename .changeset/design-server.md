New package: Pikku Studio. Its backend lists your projects (on this computer, in Fabric, or both), signs in locally or with Fabric by code, lets you choose an AI (your own key, a subscription, or Fabric), and runs each project in its own git worktree behind one address. It also carries the design server behind the console's Design page, which `pikku dev` now loads from `@pikku/studio/design`.
