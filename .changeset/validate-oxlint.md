`pikku validate` and `pikku fabric validate` now require the app's own oxlint and run it. Webhook verification helpers are async, and a caller that forgets `await` holds a truthy Promise, so `if (!verify(sig)) reject()` accepts every request while `tsc` stays silent; the type-aware `typescript/no-misused-promises` and `typescript/no-floating-promises` rules flag every form of it. Validate reports `oxlint-not-installed` (add `oxlint` and `oxlint-tsgolint` as devDependencies), `oxlint-config-missing`, `oxlint-rule-missing` (both rules must resolve to `error` through `extends` and `overrides`, with the `typescript` plugin on) and `oxlint-type-aware-off` (set `options.typeAware` or pass `--type-aware` in the lint script), each with the exact snippet to add. As the last step it then runs `oxlint --type-aware` read-only (never `--fix`) over `srcDirectories`, skipping the scaffold directory, `.pikku`, `*.gen.ts`, `node_modules` and `dist`, and reports each diagnostic as `oxlint-<plugin>-<rule>` at file:line with oxlint's own severity, the first 50 plus a count. A crash, a timeout (`validate.oxlint.timeoutSeconds`, default 300) or a run that lints no files is reported as a finding. All of these ids honour `validate.rules["<id>"]` (`"off"`, `"warn"`, `"error"`); `"oxlint-run": "off"` skips the run. Errors by default: apps that do not comply fail validate until fixed.

`pikku enable oxlint` does the setup in one step: it adds `oxlint` and `oxlint-tsgolint` as devDependencies (with the package manager the lockfile names, and installs them), creates `.oxlintrc.json` or merges the plugin, the two rules at `error` and `options.typeAware` into an existing one without dropping the rest, adds or fixes the `lint` script, then re-runs the setup check. It only touches configuration and dependencies, never source, and never passes `--fix`. A `.oxlintrc.jsonc` or `oxlint.config.ts` is not rewritten: the exact snippet is printed and the command exits non-zero. `--dry-run` prints the plan and diffs and writes nothing. The oxlint validate findings now end with "Run `pikku enable oxlint`".
