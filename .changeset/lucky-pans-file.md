Add `pikku fabric changes file`, so an item decided outside the panel — in a call, a
thread, a spec — reaches the same queue as one circled in a deployed stage. It carries the
words only; the screenshot, the circled elements and the build stay the panel's to supply.
`--body-file` takes the body from a file, because a real one has newlines in it.
