# A resumed turn is as interruptible as the first one

Resuming after an approval registers for interruption on the same terms as the
original turn.

It is the same person listening to the same voice, so the reason to allow
interruption has not changed. And after an approval is precisely where most of
the reply gets spoken: an approved delete is followed by the agent describing
what it did, which is a normal thing for a listener to talk over.

**What this rules out:** treating the resume as a short continuation not worth
wiring for interruption. By volume of speech it is usually the larger half of
the exchange.
