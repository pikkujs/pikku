# Decisions

A rule that was chosen, and what it rules out.

<!-- pikku:knowledge-index -->

- [A channel with auth false marks its connect and disconnect handlers sessionless](a-channel-with-auth-false-marks-its-connect-and-disconnect-sessionless.md) — The inspector synthesises metadata for a channel's connect and disconnect functions and sets sessionless from the channel's auth
- [A declared scope id never shadows a definition](a-declared-scope-id-never-shadows-a-definition.md) — A bare declareScopes id is added only when no definition already holds it, so an addon's richer scope tree is kept
- [A disabled function is left out of the build, and anything that still references it fails the build](a-disabled-function-is-left-out-and-a-reference-to-it-fails-the-build.md) — A function declared with disabled true or a reason string is recorded only in functions.disabled, and every reference to it is critical PKU562 naming both sides
- [A workflow DSL step's virtual user is the literal name written in its options object](a-dsl-step-virtual-user-is-the-literal-name-in-its-options.md) — The DSL extractor reads a step's virtual user from a property access or string-keyed element access in the options literal, and leaves it undefined when the value is not static
- [A feature flag's anyOf is read from the AST, and an empty anyOf is refused](a-feature-flags-anyof-is-read-from-the-ast-and-an-empty-list-is-refused.md) — add-feature-flag reads the scope names in anyOf statically, refuses a non-array or empty anyOf, and refuses a flag name containing the scope separator
- [A global permission is recorded so codegen imports the file that registers it](a-global-permission-is-imported-by-codegen.md) — addGlobalPermission calls are recorded in permissions.global and the generated permissions file imports each one, because a global permission registers at module evaluation and nothing else is guaranteed to load its file
- [A string array with one computed entry reads as absent, not as its literal entries](a-non-literal-string-array-reads-as-absent.md) — stringArrayProperty returns undefined unless every element of the array is a string literal
- [A permission whose data parameter starts with an underscore takes no data](a-permission-with-an-underscore-data-parameter-takes-no-data.md) — An underscore-prefixed data parameter marks a permission as auth-only, and pikkuAuth always has no data
- [A pikku helper is identified by what its callee resolves to, not how it is spelled](a-pikku-helper-is-identified-by-what-its-callee-resolves-to.md) — Middleware, permission, auth and pikkuFunc calls are matched through import aliases, namespace imports, re-exports and const bindings, and a gate helper used as a value is reported as PKU577
- [A provider-login virtual user is never runnable, even when declared runnable](a-provider-login-virtual-user-is-never-runnable.md) — Runnable is derived from the account, so a virtual user with a provider login cannot be driven, and an explicit runnable true does not change that
- [A remote addon's bound credential or secret id must name a wired slot, or validation reports a critical error](a-remote-addon-bound-credential-or-secret-must-be-wired.md) — validateRemoteAddonAuth checks that a literal auth.credentialId or auth.secretId on a wireRemoteAddon names a declared credential or secret, and runs in every inspector pass
- [A remote addon function's contract must be zod](a-remote-addon-function-contract-must-be-zod.md) — In an addon, a remote true function typed with generics or a named source type is critical PKU922, because its contract ships in a types-only SDK
- [A route's own auth overrides its group's, and auth false on a route makes an inline function sessionless](a-route-auth-overrides-its-groups-auth.md) — The route's auth is used when it is true or false, the group's inherited value otherwise; a resolved false sets sessionless on an inline function
- [A route requires a session when any auth signal says so](a-route-requires-a-session-when-any-auth-signal-says-so.md) — Four places can demand a session for an HTTP route and they combine with OR; a scope gate counts as a session demand
- [A service factory must be a direct call, and a cast around one fails the build](a-service-factory-must-be-a-direct-call.md) — A factory export whose pikkuServices, pikkuAddonServices, pikkuWireServices, pikkuAddonWireServices, pikkuConfig, pikkuAddonConfig or pikkuServerLifecycle call sits inside a cast (as, a <T> cast or a non-null assertion) is critical PKU564, rather than being seen through; satisfies and parentheses are read through
- [A webhook source with a verify step declares a singleton credential for its secret](a-webhook-source-with-verify-gets-a-singleton-secret-credential.md) — When a webhook source has a verify step, the inspector registers a string credential named by the source unless the author sets credential
- [A wire with auth disabled cannot point at a pikkuFunc](a-wire-with-auth-disabled-cannot-point-at-a-pikkufunc.md) — A route or wiring with auth false that names a session-requiring pikkuFunc is reported as critical, and the function is not accepted
- [Addons may not call wiring helpers or declare middleware or permissions](addon-contracts-cannot-wire-or-declare-handlers.md) — Addon packages are banned from transport wirings, and their define* contracts may not carry middleware or permissions
- [An addon declaration names the secrets and credentials the app lends it](addon-declarations-name-the-secrets-and-credentials-the-app-lends-it.md) — secretGrants and credentialGrants are declared on the addon instance as lists of names the addon reads
- [An addon declares the addons it calls in package.json, and the app's uses may map only those](an-addon-declares-the-addons-it-calls.md) — pikku.uses in an addon's package.json names each addon it calls by alias and package@range; the inspector refuses a wireAddon that leaves one unmapped (PKU348), maps it to another package (PKU347) or maps a name the addon never declared (PKU355), and a malformed entry is PKU356
- [An app function nothing uses fails pikku verify, and addon functions are never judged](an-app-function-nothing-uses-fails-verify.md) — findUnusedFunctions reports an app's own function that is not wired, exposed or called by name, as error PKU563, which pikku verify treats as a failure while pikku all still builds
- [An inline wiring function is sessionless unless its helper is pikkuFunc](an-inline-wiring-function-is-sessionless-unless-built-with-pikkufunc.md) — The inspector derives sessionless for a function inlined into a wiring from the name of the helper that built it
- [better-auth's admin plugin is refused in favour of pikkuBan](better-auth-admin-plugin-is-refused.md) — Wiring admin() in pikkuBetterAuth throws at build time, and the error names pikkuBan() as the replacement
- [Every pikkuStudio field must be a literal, or the build reports a critical error](pikku-studio-fields-must-be-literals.md) — add-pikku-studio reads the manifest and each screen by AST and reports ADDON_SCREENS_NOT_STATIC (PKU345) for a non-literal value, a spread or a value outside a field's allowed set
- [pikkuStudio fails the build on a duplicate path, a title missing from en.json, or a badge naming no function](pikku-studio-fails-the-build-on-what-studio-cannot-render.md) — validatePikkuStudio reports PKU357 for a path used twice, PKU358 for a title key missing from messages/en.json and PKU359 for a nav badge that names no function of the addon; a key missing from another locale is only a warning
- [A non-literal global grant is recorded as its source text, not dropped](inspector-records-a-non-literal-global-grant-as-source-text.md) — globalSecrets and globalCredentials on a wireAddon keep a computed value as the expression's source text
- [Only one pikkuBetterAuth export is allowed per codebase](only-one-pikku-better-auth-export-per-codebase.md) — pikkuBetterAuth must be an exported const, and a second definition is refused with the first file named
- [Printed unions are sorted by text, with null and undefined last](printed-unions-are-sorted-by-text.md) — Every type string entering the typesMap has its unions' members sorted alphabetically by both inspectors, and a union of literals given as CLI choices is sorted too
- [A versioned remote addon's SDK metadata is kept apart from addonFunctions](remote-addon-sdk-metadata-is-kept-apart-from-addon-functions.md) — The functions meta of a synced SDK loads into state.remoteAddonFunctions, never addonFunctions, and only when the SDK matches pikku-addons.lock
- [An undeclared scope and a secret service passed under another name are critical diagnostics](scope-references-and-secret-aliases-are-critical-diagnostics.md) — Post-processing reports a function that requires an undeclared scope, and a function-facing service that is a SecretService under another name
- [Scope segments may not be wildcards or contain colons](scope-segments-may-not-be-wildcards-or-contain-colons.md) — The inspector refuses an empty scope segment, a segment containing the separator, and a literal wildcard segment
- [Shorthand permission entries are extracted, so the audit never reads a guarded function as open](shorthand-permission-entries-are-extracted.md) — extractPermissionPikkuNames reads { canAdminOrg } shorthand entries in a permissions record as names, as the runtime does
- [System roles must declare literal, unqualified scopes](system-roles-declare-literal-unqualified-scopes.md) — A system role needs a literal scopes array of string literals, and its name may not contain the scope separator
- [The inspector records an agent's permissions only to aggregate the services they need, never to check access](the-inspector-records-agent-permissions-only-to-aggregate-services.md) — addAgent adds the agent's permission names to usedPermissions, and post-process reads that set only to collect each permission's services
- [Vault secrets reach no sink, and PII is kept out of logs, the console and webhooks only](vault-secrets-reach-no-sink-and-pii-stays-out-of-logs-and-webhooks.md) — check-classified-sinks rejects revealed secrets in every listed sink and PII only in the logger, console and webhook sinks
- [Webhook gateway wrappers are registered sessionless, and gateway auth is enforced inside the handler call](webhook-gateway-wrappers-are-sessionless-and-gateway-auth-runs-inside-the-handler.md) — The inspector and the runtime both register a webhook gateway's POST and verify routes as sessionless with auth false, so the route never demands a session and the gateway's own auth flag is applied only when the handler runs
