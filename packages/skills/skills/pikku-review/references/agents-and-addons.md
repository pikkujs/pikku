# Agents and addons

Read `pikku-agent` or `pikku-addon` first. Both let code reach further than it looks.

- Can an anonymous caller run the agent and spend model money? Can a caller choose the model or its parameters?
- Which tools can the agent call, and with whose authority? Can a prompt make it act for another user?
- Does an agent tool that writes need an approval?
- Which addon functions does `wireAddon` expose, and is each one meant to be public?
- Do addon routes or streams apply the app's auth, or their own?
