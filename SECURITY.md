# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to **security@pikku.dev**.
Do not open a public issue or pull request for them.

If GitHub private vulnerability reporting is enabled on this repository, you can
use it instead.

Include:

- the affected package and version
- steps to reproduce
- the impact, as you understand it

We will acknowledge your report and work on a fix. We do not run a bounty
programme and we do not promise response or fix times.

## Supported versions

Only the latest release of each package is supported. Please check that the
problem is present in the latest release before reporting it.
