The public surface doc describes `pikkuFunc` and `pikkuSessionlessFunc` by the overloads that take a body. An overload tagged `@hidden` stays out of an export's signature and option keys, and the mock overloads carry that tag. The `pikkuAuth` and `pikkuApprovalDescription` examples are real code from the online-shop template, so neither shows an escaped code fence.
