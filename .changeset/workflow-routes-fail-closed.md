The routes generated by `scaffold.workflow` and `scaffold.agent` now require a session and reach only workflows and agents marked `expose: true`; start routes validate input against the declared schema. Anonymous access needs `expose: true` plus an explicit `auth: false`, through new `/anonymous` routes. Status routes refuse runs with no owner, `workflow.approval()` must declare `approvers` (PKU645), `expose: true` on a workflow no longer publishes it as an RPC, the console run stream requires its scope, and `pikku validate` exits non-zero on errors. Breaking: see `docs/MIGRATION.md`.
