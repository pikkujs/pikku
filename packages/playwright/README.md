# @pikku/playwright

Playwright browser driver for Pikku scenario steps. Lets `pikkuScenario` tests
drive a real browser.

## Install

```bash
npm install -D @pikku/playwright
```

## Usage

Register the driver in your scenario setup, then use browser steps inside
`pikkuScenario`. Run scenarios with:

```bash
npx pikku scenario run
```
